# Ý 18 — Thứ cuối cùng còn lại

**Dán ảnh / video cho ý này vào đây:** bấm **Add file → Upload files** (góc phải, ngay trong thư mục này) → kéo file vào → **Commit changes**.

Ý dài ****. Nhiều file → chạy lần lượt theo tên file (chia đều thời gian). Video: lấy từ đầu clip, tắt tiếng; clip ngắn hơn ý thì lặp lại.

> Vielleicht ist diese Platte eines Tages das Letzte, was von uns übrig bleibt.

**Nghĩa:** Có lẽ một ngày nào đó, chiếc đĩa này là thứ cuối cùng còn lại của chúng ta.

**Gợi ý hình:** Đĩa vàng lơ lửng trong bóng tối, kết thúc u buồn.

**Phương án khác:** Dùng lại ảnh Đĩa Vàng, zoom ra rồi tối dần.

**Từ khóa tìm:** đĩa vàng trong bóng tối
