# Ý 07 — Điện yếu dần – tắt từng thiết bị – sẽ im lặng

**Dán ảnh / video cho ý này vào đây:** bấm **Add file → Upload files** (góc phải, ngay trong thư mục này) → kéo file vào → **Commit changes**.

Ý dài ****. Nhiều file → chạy lần lượt theo tên file (chia đều thời gian). Video: lấy từ đầu clip, tắt tiếng; clip ngắn hơn ý thì lặp lại.

> Ihr Strom wird jedes Jahr schwächer. Ingenieure schalten ein Instrument nach dem anderen ab, damit sie noch ein bisschen länger sprechen kann. Irgendwann in den nächsten Jahren wird sie für immer verstummen.

**Nghĩa:** Điện năng của tàu yếu đi mỗi năm. Các kỹ sư tắt từng thiết bị một để tàu có thể 'nói' thêm một chút nữa. Một lúc nào đó trong vài năm tới, tàu sẽ im lặng mãi mãi.

**Gợi ý hình:** Bóng đèn mờ dần → phòng điều khiển JPL, kỹ sư → Voyager bé dần giữa bóng tối. Nên dùng 2–3 đoạn video ngắn cho ý này (mỗi đoạn chạy lần lượt).

**Phương án khác:** Pexels: 'light bulb flicker dark', 'mission control'; images.nasa.gov: 'JPL Voyager team'.

**Từ khóa tìm:** bóng đèn mờ dần, phòng điều khiển nasa jpl, voyager cô độc giữa vũ trụ

**Tìm bằng tiếng Anh (nhiều kết quả hơn):** light bulb fading dark, JPL mission control Voyager team, Voyager alone in space
