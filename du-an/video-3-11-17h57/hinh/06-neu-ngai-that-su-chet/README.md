# Ý 06 — Nếu Ngài thật sự chết

**Dán ảnh / video cho ý này vào đây:** bấm **Add file → Upload files** (góc phải, ngay trong thư mục này) → kéo file vào → **Commit changes**.

Ý dài **3.6 giây** (từ giây 17.0 đến 20.6). Nhiều file → chạy lần lượt theo tên file (chia đều thời gian). Video: lấy từ đầu clip, tắt tiếng; clip ngắn hơn ý thì lặp lại.

> doch dieses Opfer ist nichts im Vergleich zu dem, was passiert, wenn er tatsächlich stirbt.

**Nghĩa:** nhưng sự hy sinh đó chẳng là gì so với điều sẽ xảy ra nếu Ngài thật sự chết.

**Gợi ý hình:** Ngai Vàng tối om, ánh sáng tắt dần, vết nứt chạy khắp ngai; không khí tận thế.

**Phương án khác:** Hình Ngai Vàng tông tối, hoặc chữ to 'WENN ER STIRBT' trên nền đen.

**Từ khóa tìm:** ngai vàng tối, hoàng đế chết

**Tìm bằng tiếng Anh (nhiều kết quả hơn):** Golden Throne dark, Emperor dying
