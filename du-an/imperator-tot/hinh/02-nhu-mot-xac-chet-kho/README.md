# Ý 02 — Như một xác chết khô

**Dán ảnh / video cho ý này vào đây:** bấm **Add file → Upload files** (góc phải, ngay trong thư mục này) → kéo file vào → **Commit changes**.

Ý dài **3.5 giây** (từ giây 5.8 đến 9.3). Nhiều file → chạy lần lượt theo tên file (chia đều thời gian). Video: lấy từ đầu clip, tắt tiếng; clip ngắn hơn ý thì lặp lại.

> Er gleicht einer vertrockneten Leiche, die regungslos vor sich hin vegetiert.

**Nghĩa:** Ngài trông như một xác chết khô quắt, nằm bất động sống lay lắt.

**Phương án khác:** Artwork “Corpse Emperor” cận mặt (fan art nổi tiếng), hoặc ảnh mặt xác ướp khô có chỉnh tông vàng.
