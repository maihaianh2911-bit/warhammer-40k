# Ý 05 — Theo mọi chuẩn mực: đó là cái chết

**Dán ảnh / video cho ý này vào đây:** bấm **Add file → Upload files** (góc phải, ngay trong thư mục này) → kéo file vào → **Commit changes**.

Ý dài **2.0 giây** (từ giây 17.5 đến 19.5). Nhiều file → chạy lần lượt theo tên file (chia đều thời gian). Video: lấy từ đầu clip, tắt tiếng; clip ngắn hơn ý thì lặp lại.

> Nach allen gängigen Maßstäben ist das der Tod.

**Nghĩa:** Theo mọi tiêu chuẩn thông thường, đó chính là cái chết.

**Gợi ý hình:** Màn hình theo dõi sinh tồn kiểu gothic-cơ khí (xanh lục mờ, vỏ đồng thau) hiện đường thẳng — không nhịp tim; Hoàng đế mờ phía sau.

**Phương án khác:** Nền đen + chữ lớn “TOT” / đường điện tim thẳng màu vàng.

**Từ khóa tìm:** màn hình điện tim đường thẳng, máy theo dõi nhịp tim ngừng đập

**Tìm bằng tiếng Anh (nhiều kết quả hơn):** flatline monitor, cogitator, Adeptus Mechanicus screen
