# Ý 12 — Can thiệp vào lúc nguy cấp

**Dán ảnh / video cho ý này vào đây:** bấm **Add file → Upload files** (góc phải, ngay trong thư mục này) → kéo file vào → **Commit changes**.

Ý dài **4.9 giây** (từ giây 45.2 đến 50.1). Nhiều file → chạy lần lượt theo tên file (chia đều thời gian). Video: lấy từ đầu clip, tắt tiếng; clip ngắn hơn ý thì lặp lại.

> Dadurch kann er gelegentlich kommunizieren oder in Momenten größter Not sogar direkt in das Geschehen eingreifen.
