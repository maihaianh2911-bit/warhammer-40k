# Ý 03 — Kẻ phản bội gọi là “Hoàng đế Xác chết”

**Dán ảnh / video cho ý này vào đây:** bấm **Add file → Upload files** (góc phải, ngay trong thư mục này) → kéo file vào → **Commit changes**.

Ý dài **4.2 giây** (từ giây 9.3 đến 13.5). Nhiều file → chạy lần lượt theo tên file (chia đều thời gian). Video: lấy từ đầu clip, tắt tiếng; clip ngắn hơn ý thì lặp lại.

> Dass ihn die Verräter spöttisch als „Leichen-Imperator“ bezeichnen, ist also keineswegs übertrieben.

**Nghĩa:** Nên việc bọn phản bội chế nhạo gọi Ngài là “Hoàng đế Xác chết” cũng chẳng hề quá lời.

**Gợi ý hình:** Một Chaos Space Marine (giáp đen-đỏ, sừng, mắt đỏ phát sáng) đứng trong bóng tối, cười nhạo khinh bỉ; phía sau mờ mờ bóng Ngai Vàng.

**Phương án khác:** Artwork Black Legion / Abaddon cười, hoặc Chaos Marine trong Space Marine 2.

**Từ khóa tìm:** chaos space marine, binh đoàn đen black legion, lính phản bội warhammer

**Tìm bằng tiếng Anh (nhiều kết quả hơn):** Chaos Space Marine, Black Legion, traitor marine
