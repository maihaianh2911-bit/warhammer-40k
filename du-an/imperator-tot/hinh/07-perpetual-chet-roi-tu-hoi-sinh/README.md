# Ý 07 — Perpetual chết rồi tự hồi sinh

**Dán ảnh / video cho ý này vào đây:** bấm **Add file → Upload files** (góc phải, ngay trong thư mục này) → kéo file vào → **Commit changes**.

Ý dài **5.3 giây** (từ giây 24.3 đến 29.6). Nhiều file → chạy lần lượt theo tên file (chia đều thời gian). Video: lấy từ đầu clip, tắt tiếng; clip ngắn hơn ý thì lặp lại.

> Wenn ein Perpetual stirbt, ist sein Körper nur so lange tot, bis er sich von selbst wieder vollständig regeneriert hat.

**Nghĩa:** Khi một Perpetual chết, cơ thể chỉ chết cho tới khi tự tái tạo hoàn toàn.

**Gợi ý hình:** Một cơ thể nằm trên phiến đá cổ, nửa người là xác khô, nửa người đang lành lại — da hồng trở lại, ánh vàng tỏa ra từ vết thương đang khép.

**Phương án khác:** Hình tượng phượng hoàng tái sinh từ tro, tông vàng-đỏ.

**Từ khóa tìm:** bất tử hồi sinh, cơ thể tái tạo, phượng hoàng tái sinh

**Tìm bằng tiếng Anh (nhiều kết quả hơn):** regeneration, resurrection, immortal rebirth
