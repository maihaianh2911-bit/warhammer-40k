# Ý 08 — Không bao giờ chết hẳn

**Dán ảnh / video cho ý này vào đây:** bấm **Add file → Upload files** (góc phải, ngay trong thư mục này) → kéo file vào → **Commit changes**.

Ý dài **2.0 giây** (từ giây 29.6 đến 31.6). Nhiều file → chạy lần lượt theo tên file (chia đều thời gian). Video: lấy từ đầu clip, tắt tiếng; clip ngắn hơn ý thì lặp lại.

> Er kann also niemals endgültig sterben.

**Nghĩa:** Vì vậy Ngài không bao giờ có thể chết hẳn.

**Gợi ý hình:** Chữ ∞ hoặc vòng tròn rắn tự cắn đuôi (ouroboros) bằng vàng phát sáng trên nền đen, khói nến.

**Phương án khác:** Nền đen + chữ lớn “NIEMALS”.

**Từ khóa tìm:** rắn tự cắn đuôi ouroboros, biểu tượng vĩnh cửu vàng

**Tìm bằng tiếng Anh (nhiều kết quả hơn):** ouroboros gold, eternity symbol
