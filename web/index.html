Kết nối GitHub (làm một lần)

Trang lưu kịch bản, giọng và hình thẳng vào repo của bạn, nên cần một mã GitHub có quyền ghi vào repo này.

  1. Mở trang tạo mã GitHub (đăng nhập GitHub nếu được hỏi).
  2. Token name: gõ gì cũng được, vd xuong ghep hinh. Expiration: chọn No expiration hoặc 1 năm.
  3. Repository access → Only select repositories → chọn warhammer-40k.
  4. Permissions → Contents → chọn Read and write.
  5. Bấm Generate token, copy mã (bắt đầu bằng github_pat_) và dán vào ô dưới.

Mã chỉ lưu trong trình duyệt này, không gửi đi đâu ngoài GitHub.
